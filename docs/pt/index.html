Do texto na página à sessão no Claude, num clique.

A Claude Links encontra textos que define por regex e transforma-os em ligações que abrem uma nova sessão no separador Code do Claude Desktop, com a mensagem já escrita.

Ver no GitHub Instalar

// como funciona

Um aviso passa a atalho

Uma automatização publica no Discord um aviso com um comando em texto. Com uma regra configurada, o comando passa a ser uma ligação; o clique abre o Claude com o pedido pronto.

Antes · texto simples

[TASK-123] Erro ao enviar mensagem

Fazer a triagem com /triagem TASK-123

→

Depois · ligação

[TASK-123] Erro ao enviar mensagem

Fazer a triagem com /triagem TASK-123

Claude Desktop · nova sessãoExecuta a skill triagem na TASK-123

Encontra

O script corre nas páginas adicionadas e acompanha o conteúdo que vai chegando, como as mensagens novas do Discord.

Substitui

Cada trecho que corresponde a uma regra passa a ser uma ligação claude://code/new, construída com o valor e a pasta da regra.

Abre

O clique abre uma sessão no Claude Desktop com a mensagem escrita. Nada é enviado sozinho: verifica-a e prime Enter.

Carregar no navegador

Enquanto não está na Chrome Web Store, a extensão é carregada a partir do código.

Passo a passo

  1. Transfira ou clone o repositório.
  2. Abra brave://extensions ou chrome://extensions.
  3. Ative o Modo de programador.
  4. Clique em Carregar expandida e escolha a pasta.
  5. Fixe o ícone da extensão na barra.

Regras por página

Clique no ícone da extensão para ver a lista de páginas. O botão + adiciona uma nova, já com o domínio do separador atual preenchido. Ao guardar, o navegador pede permissão para a extensão correr nesse site; sem ela, a extensão não altera a página.

CampoO que é
PáginaDomínio onde as regras se aplicam, ex.: discord.com. Os subdomínios também correspondem.
ChaveRegex que identifica o texto a substituir. Validada enquanto escreve.
ValorMensagem enviada ao Claude (parâmetro q). Aceita $1, $2… dos grupos da chave.
PastaOpcional. Pasta onde a sessão abre. Vazio = pasta predefinida do Claude Desktop.
▶Aplica a regra de imediato no separador aberto, sem guardar, e indica quantos trechos passaram a ligação.

Exemplo de regra

chave  /(triagem|abrir-pedido)\s+([A-Z][A-Z0-9]*-\d+)
valor  Executa a skill $1 na $2
link   claude://code/new?q=Executa%20a%20skill%20triagem%20na%20TASK-123

Bom saber

Comportamentos do Claude Desktop e dos sites que moldaram a extensão.

/

Comandos com barra não funcionam no valor. O Claude Desktop substitui a barra inicial do q por outro carácter, por isso o texto não é um comando. Peça a skill por texto: “Executa a skill X na Y”.

#

O Discord não aceita estas ligações na mensagem. Só torna clicáveis as que começam por http(s). Por isso a substituição acontece no navegador.

!

Confirmação na primeira vez. O navegador pergunta se pode abrir o Claude ao clicar na primeira ligação claude://.

⌂

Com pasta, o Claude Desktop pede para confiar nela em cada ligação, mesmo que já a tenha autorizado antes. Deixe a pasta vazia para evitar essa pergunta.

$

O texto capturado por $1, $2… vem da página, e qualquer pessoa do canal pode tê-lo escrito. Quebras de linha e caracteres invisíveis passam a espaço e cada grupo é cortado em 200 caracteres. Passe o rato sobre a ligação para ver a mensagem completa e verifique-a antes de premir Enter.
