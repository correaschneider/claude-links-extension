Dal testo nella pagina a una sessione di Claude, con un clic.

Claude Links trova i testi che definisci con una regex e li trasforma in link che aprono una nuova sessione nella scheda Code di Claude Desktop, con il messaggio già scritto.

Vedi su GitHub Installa

// come funziona

Un avviso diventa una scorciatoia

Un’automazione pubblica su Discord un avviso con un comando in testo. Con una regola impostata, il comando diventa un link; il clic apre Claude con la richiesta pronta.

Prima · testo semplice

[TASK-123] Errore nell’invio del messaggio

Fare il triage con /triage TASK-123

→

Dopo · link

[TASK-123] Errore nell’invio del messaggio

Fare il triage con /triage TASK-123

Claude Desktop · nuova sessioneEsegui la skill triage su TASK-123

Trova

Lo script viene eseguito sulle pagine aggiunte e segue i contenuti che arrivano, come i nuovi messaggi di Discord.

Sostituisce

Ogni corrispondenza di una regola diventa un link claude://code/new, costruito con il valore e la cartella della regola.

Apre

Il clic apre una sessione di Claude Desktop con il messaggio scritto. Nulla viene inviato da solo: lo controlli e premi Invio.

// installazione

Caricarla nel browser

Finché non è sul Chrome Web Store, l’estensione si carica dal codice sorgente.

Passo dopo passo

  1. Scarica o clona il repository.
  2. Apri brave://extensions o chrome://extensions.
  3. Attiva la Modalità sviluppatore.
  4. Clicca su Carica estensione non pacchettizzata e scegli la cartella.
  5. Fissa l’icona dell’estensione nella barra.

Regole per pagina

Clicca sull’icona dell’estensione per vedere l’elenco delle pagine. Il pulsante + ne aggiunge una nuova con il dominio della scheda corrente già compilato. Quando salvi, il browser chiede il permesso perché l’estensione funzioni su quel sito; senza, l’estensione non tocca la pagina.

CampoChe cos’è
PaginaDominio in cui valgono le regole, ad es. discord.com. Anche i sottodomini corrispondono.
ChiaveRegex che trova il testo da sostituire. Validata mentre scrivi.
ValoreMessaggio inviato a Claude (parametro q). Accetta $1, $2… dai gruppi della chiave.
CartellaFacoltativa. Cartella in cui si apre la sessione. Vuota = cartella predefinita di Claude Desktop.
▶Applica subito la regola alla scheda aperta, senza salvare, e indica quante corrispondenze sono diventate link.

Esempio di regola

chiave  /(triage|apri-ticket)\s+([A-Z][A-Z0-9]*-\d+)
valore  Esegui la skill $1 su $2
link    claude://code/new?q=Esegui%20la%20skill%20triage%20su%20TASK-123

// limitazioni

Da sapere

Comportamenti di Claude Desktop e dei siti che hanno dato forma all’estensione.

/

I comandi con la barra non funzionano nel valore. Claude Desktop sostituisce la barra iniziale di q con un altro carattere, quindi il testo non è un comando. Chiedi la skill a parole: “Esegui la skill X su Y”.

#

Discord non accetta questi link in un messaggio. Rende cliccabili solo quelli che iniziano con http(s). Per questo la sostituzione avviene nel browser.

!

Conferma la prima volta. Il browser chiede se può aprire Claude quando clicchi sul primo link claude://.
