Del texto en la página a una sesión de Claude, en un clic.

Claude Links encuentra textos que defines con una regex y los convierte en enlaces que abren una nueva sesión en la pestaña Code de Claude Desktop, con el mensaje ya escrito.

Ver en GitHub Instalar

// cómo funciona

Un aviso se convierte en atajo

Una automatización publica en Discord un aviso con un comando en texto. Con una regla configurada, el comando se convierte en enlace; el clic abre Claude con la petición lista.

Antes · texto plano

[TASK-123] Error al enviar el mensaje

Hacer el triaje con /triaje TASK-123

→

Después · enlace

[TASK-123] Error al enviar el mensaje

Hacer el triaje con /triaje TASK-123

Claude Desktop · nueva sesiónEjecuta la skill triaje en TASK-123

Encuentra

El script se ejecuta en las páginas que añadiste y sigue el contenido que va llegando, como los mensajes nuevos de Discord.

Sustituye

Cada coincidencia de una regla se convierte en un enlace claude://code/new, construido con el valor y la carpeta de la regla.

Abre

El clic abre una sesión de Claude Desktop con el mensaje escrito. No se envía nada solo: lo revisas y pulsas Enter.

Cargar en el navegador

Mientras no esté en Chrome Web Store, la extensión se carga desde el código fuente.

Paso a paso

  1. Descarga o clona el repositorio.
  2. Abre brave://extensions o chrome://extensions.
  3. Activa el Modo de desarrollador.
  4. Haz clic en Cargar descomprimida y elige la carpeta.
  5. Fija el icono de la extensión en la barra.

Reglas por página

Haz clic en el icono de la extensión para ver la lista de páginas. El botón + añade una nueva, con el dominio de la pestaña actual ya rellenado. Al guardar, el navegador pide permiso para que la extensión se ejecute en ese sitio; sin él, la extensión no toca la página.

CampoQué es
PáginaDominio donde se aplican las reglas, p. ej. discord.com. Los subdominios también coinciden.
ClaveRegex que encuentra el texto a sustituir. Se valida mientras escribes.
ValorMensaje que se envía a Claude (parámetro q). Acepta $1, $2… de los grupos de la clave.
CarpetaOpcional. Carpeta donde se abre la sesión. Vacío = carpeta predeterminada de Claude Desktop.
▶Aplica la regla al momento en la pestaña abierta, sin guardar, e indica cuántas coincidencias se convirtieron en enlaces.

Ejemplo de regla

clave  /(triaje|abrir-ticket)\s+([A-Z][A-Z0-9]*-\d+)
valor  Ejecuta la skill $1 en $2
enlace  claude://code/new?q=Ejecuta%20la%20skill%20triaje%20en%20TASK-123

Conviene saber

Comportamientos de Claude Desktop y de los sitios que dieron forma a la extensión.

/

Los comandos con barra no funcionan en el valor. Claude Desktop reemplaza la barra inicial de q por otro carácter, así que el texto no es un comando. Pide la skill con texto: “Ejecuta la skill X en Y”.

#

Discord no acepta estos enlaces en un mensaje. Solo hace clicables los que empiezan por http(s). Por eso la sustitución ocurre en el navegador.

!

Confirmación la primera vez. El navegador pregunta si puede abrir Claude al hacer clic en el primer enlace claude://.
