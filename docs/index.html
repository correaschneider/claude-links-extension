Do texto na página à sessão no Claude, em um clique.

A Claude Links encontra textos que você define por regex e os transforma em links que abrem uma sessão nova na aba Code do Claude Desktop, com a mensagem já digitada.

// como funciona

Um aviso vira um atalho

Uma automação manda no Discord um aviso com um comando em texto. Com uma regra cadastrada, o comando vira um link; o clique abre o Claude com o pedido pronto.

Antes · texto puro

[TASK-123] Erro ao enviar mensagem

Fazer a triagem com /triagem TASK-123

→

Depois · link

[TASK-123] Erro ao enviar mensagem

Fazer a triagem com /triagem TASK-123

Claude Desktop · nova sessãoRode a skill triagem na TASK-123

Encontra

O script roda nas páginas cadastradas e acompanha o conteúdo que vai chegando, como as mensagens novas do Discord.

Troca

Cada trecho que casa com uma regra vira um link claude://code/new, montado com o valor e a pasta da regra.

Abre

O clique abre uma sessão no Claude Desktop com a mensagem digitada. Nada é enviado sozinho: você confere e aperta Enter.

Carregar no navegador

A extensão ainda não está na Chrome Web Store. Ela é carregada a partir do código.

Passo a passo

  1. Baixe ou clone o repositório.
  2. Abra brave://extensions ou chrome://extensions.
  3. Ative o Modo de desenvolvedor.
  4. Clique em Carregar sem compactação e escolha a pasta.
  5. Fixe o ícone da extensão na barra.

Regras por página

Clique no ícone da extensão para ver a lista de páginas. O botão + cadastra uma nova, já com o domínio da aba atual preenchido.

CampoO que é
PáginaDomínio onde as regras valem, ex.: discord.com. Subdomínios também casam.
ChaveRegex que identifica o texto a trocar.
ValorMensagem que vai para o Claude (parâmetro q). Aceita $1, $2… com os grupos da chave.
FolderOpcional. Pasta onde a sessão abre. Vazio = pasta padrão do Claude Desktop.

Exemplo de regra

chave  /(triagem|abrir-chamado)\s+([A-Z][A-Z0-9]*-\d+)
valor  Rode a skill $1 na $2
link   claude://code/new?q=Rode%20a%20skill%20triagem%20na%20TASK-123

Bom saber

Comportamentos do Claude Desktop e dos sites que moldaram a extensão.

/

Comandos com barra não funcionam no valor. O Claude Desktop troca a barra inicial do q por outro caractere, então o texto não vira comando. Peça a skill em texto: “Rode a skill X na Y”.

#

O Discord não aceita esses links na mensagem. Ele só torna clicável o que começa com http(s). Por isso a troca acontece no navegador.

!

Confirmação na primeira vez. O navegador pergunta se pode abrir o Claude ao clicar no primeiro link claude://.
