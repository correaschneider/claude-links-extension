// chrome · brave extension

From text on a page to a Claude session, in one click.

Claude Links finds text you define with a regex and turns it into links that open a new session in the Code tab of Claude Desktop, with the message already typed.

View on GitHub Install

// how it works

A notice becomes a shortcut

An automation posts a command as text in Discord. With a rule in place, the command becomes a link; one click opens Claude with the request ready.

Before · plain text

[TASK-123] Error sending message

Run the triage with /triage TASK-123

→

After · link

[TASK-123] Error sending message

Run the triage with /triage TASK-123

Claude Desktop · new sessionRun the skill triage on TASK-123

Finds

The script runs on the pages you added and follows new content as it arrives, like new Discord messages.

Replaces

Each match of a rule becomes a claude://code/new link, built from the rule’s value and folder.

Opens

The click opens a Claude Desktop session with the message typed. Nothing is sent on its own: you review it and press Enter.

// installation

Load it in the browser

Until it is on the Chrome Web Store, the extension is loaded from the source code.

Step by step

  1. Download or clone the repository.
  2. Open brave://extensions or chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the folder.
  5. Pin the extension icon to the toolbar.

From the terminal

# clone the code
git clone https://github.com/correaschneider/claude-links-extension.git

# after changing files:
# ↻ on the extension + reload the tab

// configuration

Rules per page

Click the extension icon to see the list of pages. The + button adds a new one with the current tab’s domain filled in. When you save, the browser asks for permission for the extension to run on that site; without it, the extension does not touch the page.

FieldWhat it is
PageDomain where the rules apply, e.g. discord.com. Subdomains match too.
KeyRegex that finds the text to replace. Validated as you type.
ValueMessage sent to Claude (the q parameter). Accepts $1, $2… from the key’s groups.
FolderOptional. Folder where the session opens. Empty = Claude Desktop’s default folder.
▶Applies the rule to the open tab right away, without saving, and tells you how many matches became links.

Example rule

key    /(triage|open-ticket)\s+([A-Z][A-Z0-9]*-\d+)
value  Run the skill $1 on $2
link   claude://code/new?q=Run%20the%20skill%20triage%20on%20TASK-123

// limitations

Good to know

Claude Desktop and website behaviors that shaped the extension.

/

Commands with a slash don’t work in the value. Claude Desktop replaces the leading slash of q with another character, so the text is not a command. Ask for the skill in words: “Run the skill X on Y”.

#

Discord doesn’t accept these links in a message. It only makes http(s) links clickable. That’s why the replacement happens in the browser.

!

Confirmation the first time. The browser asks whether it may open Claude when you click the first claude:// link.

⌂

With a folder, Claude Desktop asks you to trust it on every link, even if you already trusted it before. Leave the folder empty to skip that prompt.

$

Text captured by $1, $2… comes from the page, and anyone in the channel may have written it. Line breaks and invisible characters become spaces and each group is cut at 200 characters. Hover a link to see the full message and review it before pressing Enter.
